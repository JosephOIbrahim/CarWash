## Technical Requirements

### 1. Create CarWashRenderSettingsAPI Schema

```usda
#usda 1.0
(
    subLayers = [
        @usd/schema.usda@
    ]
)

over "GLOBAL" (
    customData = {
        string libraryName = "usdCarWash"
        string libraryPath = "."
    }
)
{
}

class "CarWashRenderSettingsAPI" (
    inherits = </APISchemaBase>
    customData = {
        string className = "CarWashRenderSettingsAPI"
        token apiSchemaType = "singleApply"
        token[] apiSchemaCanOnlyApplyTo = ["RenderSettings"]
    }
    doc = "CarWash renderer settings API schema"
)
{
    string carwash:prompt = "photorealistic 3D render" (
        doc = "AI prompt for image generation"
    )
    float carwash:depthStrength = 0.8 (
        doc = "Depth conditioning strength"
    )
    bool carwash:useDepth = true (
        doc = "Enable depth-conditioned generation"
    )
    bool carwash:useNormal = true (
        doc = "Enable normal-conditioned generation"
    )
}
```

### 2. Generate C++ Schema Code

Use `usdGenSchema` tool:
```cmd
usdGenSchema schema.usda .
```

This generates:
- `carWashRenderSettingsAPI.h`
- `carWashRenderSettingsAPI.cpp`
- `generatedSchema.usda`
- Updated `plugInfo.json`

### 3. Update plugInfo.json

Add schema type registration:
```json
{
    "Info": {
        "Types": {
            "HdCarWashRendererPlugin": { ... },
            "usdCarWashCarWashRenderSettingsAPI": {
                "alias": { "UsdSchemaBase": "CarWashRenderSettingsAPI" },
                "apiSchemaCanOnlyApplyTo": ["RenderSettings"],
                "autoGenerated": true,
                "bases": ["UsdAPISchemaBase"],
                "schemaIdentifier": "CarWashRenderSettingsAPI",
                "schemaKind": "singleApplyAPI"
            }
        }
    }
}
```
